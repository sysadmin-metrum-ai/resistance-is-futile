## Integration Gaps

### Critical (Major)

**1. verify-position.py broken (Phase 3)**
- Script calls non-existent endpoints: `/drones/{id}/takeoff`, `/drones/{id}/land`, `/drones/{id}/go_to`, `/drones/{id}/state`
- API paths wrong: uses `/api/drones/...` instead of `/drones/...`
- Impact: Position verification cannot run

**2. LED hardcoded URI bug (Phase 2)**
- `src/api/routes/led.py` lines 83, 123, 149 use `f"drone-{drone_id}"` instead of fetching from database
- Impact: LED control won't work with real drones

### Non-Critical (Minor)

**3. Unwired endpoints (Phase 1 & 2)**
- Camera API (`/images/*`) exists but not consumed by Dashboard
- LED API exists but not called from Dashboard
- SSE events endpoint exists but Dashboard polls instead
- Pre-flight check endpoint exists but not in UI
- Drone discover endpoint exists but not in UI
